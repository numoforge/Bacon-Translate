# Bacon Translate

A responsive multilingual translation web app powered by Google Translate.

## Features
- Automatic source-language detection
- Large language selection
- Translate while typing or on demand
- Swap languages, copy, paste, and clear
- Local translation history
- Light and dark themes
- Responsive mobile and desktop layout

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose the `main` branch and `/(root)`, then save.
4. Wait for the Pages deployment to finish.

The expected site URL is https://numoforge.github.io/Bacon-Translate/

## Privacy
Bacon Translate does not require an account. Translation text is sent to Google's translation service for processing. Recent history and the theme preference are stored in the browser's local storage on the device. Do not submit passwords, payment details, or other sensitive information.

## Technical note
This project uses Google's unofficial web translation endpoint. It is not an official Google Cloud Translation API integration and may be rate-limited, changed, or blocked. Availability and browser access can vary. No guarantee of uninterrupted service is made.
